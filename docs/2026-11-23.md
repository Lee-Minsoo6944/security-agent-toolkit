# 2026-11-23

## networksim · 다른 VLAN 연결하기
- 연결 전 시험 결과: unreachable
- 추가한 장치: L3-1 switch
- 연결한 장치: SW VLAN10 - L3 - SW VLAN20
- 연결 후 시험 결과: PASSES
- 서로 다른 네트워크 사이에 필요했던 기능: L3-1

### 왜 L3 switch가 필요한가
- 짧은 답: VLAN10과 VLAN20은 서로 다른 네트워크입니다. 서로 다른 네트워크 사이에서 패킷을 넘겨 주는 일(라우팅)은 L3 장비만 할 수 있어요.

1. VLAN은 네트워크를 나눠요

일반 스위치(L2)는 MAC 주소만 보고, 같은 VLAN 안에서만 프레임을 전달해요.
예를 들어 VLAN10은 192.168.10.0/24, VLAN20은 192.168.20.0/24처럼 서로 다른 IP 대역을 써요.
L2 스위치는 VLAN10에서 온 프레임을 VLAN20으로 넘기지 않아요. 그래서 연결 전 시험 결과가 unreachable이었어요.

2. 다른 대역으로 갈 때는 게이트웨이가 필요해요

PC는 목적지가 다른 대역이면, 패킷을 직접 보내지 않고 기본 게이트웨이로 보내요.
연결 전에는 그 게이트웨이 역할을 할 장비가 없었어요.

3. L3 스위치가 VLAN 사이를 이어 줘요

L3 스위치는 VLAN마다 게이트웨이 IP를 가질 수 있어요. 예를 들어 VLAN10 쪽은 192.168.10.1, VLAN20 쪽은 192.168.20.1이에요.
패킷의 IP 주소를 보고 VLAN10에서 VLAN20으로 넘겨 줘요. 이것이 라우팅이에요.
그래서 SW VLAN10 - L3 - SW VLAN20으로 연결한 뒤 시험 결과가 PASSES가 됐어요.

4. 라우터 대신 L3 스위치를 쓰는 이유

라우터로도 VLAN 사이를 이을 수 있어요.
하지만 L3 스위치는 스위칭과 라우팅을 하드웨어에서 함께 처리해서 빠르고, 포트도 많아요.
그래서 사내망에서 VLAN 사이를 이을 때 주로 L3 스위치를 써요.
