* 위치를 가르키는 말

1. 폴더 · 디렉터리 (Folder & Directory)
같은가?

디렉터리는 컴퓨터 파일 시스템 관점에서 파일들이 담겨 있는 논리적인 저장 공간(구조)을 뜻하는 기술적 용어이고, 폴더는 그래픽 사용자 인터페이스(GUI) 환경에서 서류철(Folder)의 비유를 가져와 사용자 친화적으로 부르는 이름입니다. 보통 윈도우나 맥의 화면에서 마우스로 여는 아이콘을 '폴더', 그 구조와 개념을 시스템적으로 부를 때 '디렉터리'라고 주로 표현합니다.

2. 절대경로 (Absolute Path)

파일 시스템의 가장 꼭대기인 최상위 루트(Root) 디렉터리부터 시작하여, 목적지 파일이나 폴더에 도달하기까지 거치는 모든 경로를 빠짐없이 전부 나열하는 주소입니다.

예시: 리눅스의 경우 /home/user/docs/file.txt, 윈도우의 경우 C:\Users\User\Documents\file.txt처럼 시작점(최상위 루트)이 고정되어 있어 현재 내가 어디에 있든 상관없이 항상 동일한 경로를 가리킵니다.

3. 상대경로 (Relative Path)

현재 내가 작업하고 있는 위치(현재 디렉터리, Current Directory)를 기준으로 목적지까지 찾아가는 경로입니다.

특징: 출발지가 어디냐에 따라 같은 목적지라도 경로 표현이 달라집니다. 현재 위치에서 바로 아래로 내려갈 때는 이름만 적고, 상위로 올라갈 때는 기호를 사용해 이동합니다.

4. 홈 디렉터리 (Home Directory)

현재 컴퓨터에 로그인한 개별 사용자(User)의 개인 공간이자 기본 작업 공간입니다. 각 사용자마다 고유의 홈 디렉터리가 주어져서 개인 파일이나 설정이 저장됩니다.

줄임 기호: 물결표인 ~ 기호로 줄여서 표현합니다. (예: ~/Documents)

5. . 과 ..

. (점 하나): 현재 자기 자신이 위치한 디렉터리를 가리킵니다. (Current Directory)

.. (점 둘): 현재 디렉터리보다 한 단계 위인 부모(상위) 디렉터리를 가리킵니다. (Parent Directory)

6. / 와 \ (슬래시와 역슬래시)

/ (슬래시 / Forward Slash): 리눅스(Linux), 유닉스(Unix), 맥OS(macOS) 등 유닉스 계열 운영체제나 웹(URL)에서 경로를 구분하는 기호로 사용합니다.

\ (역슬래시 / Backslash): 마이크로소프트 윈도우(Windows) 운영체제에서 파일 및 폴더 경로를 구분하는 기호로 사용합니다.


* 명령 이름의 뜻

1. pwd : Print Working Directory
현재 작업중인 디렉터리의 위치(경로)를 화면에 출력해줍니다. "내가 지금 어디에 있지?" 궁금할 때 사용합니다.

2. ls : List
현재 디렉터리에 포함된 파일과 폴더을의 목록을 화면에 나열해 줍니다.

3. cd : Change Directory
현재 작업하고 있는 디렉터리를 다른 곳으로 이동할 때 사용합니다.

4. mkdir : Make Directory
새로운 디렉터리(폴더)를 만드는 명령어입니다.

* 옵션과 플래그

1. 뜻과 역할 : 명령어의 기본적인 동작 방식을 조금 바꾸거나, 추가적인 기능을 켜고 끌 때 사용하는 부가 설정입니다. 요리할 때 기본메뉴(명령어)에 "맵게", "소스 빼고" 같은 추가 주문이나
조절옵션을 붙이는 것과 같습니다.

2. 예시 : 명령어의 구조 = 명령어 + 옵션 + 대상
  - ls -l(Long) : 파일이름을 포함한 크기, 만든날짜, 권한까지 상세한 목록을 보여줍니다.
  - ls -lh(Long Human-readable) : 사람이 읽기 편한 단위로 변환해서 보여줍니다.
