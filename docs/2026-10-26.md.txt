🐧 1. 보안 담당자와 개발자는 왜 '리눅스 명령어'를 사용할까요?
서버 환경의 표준: 전 세계의 대다수 웹 서버, 클라우드 인프라, 보안 시스템(방화벽, 침입탐지 시스템 등)은 안정성과 보안성이 뛰어난 리눅스(Linux) 기반으로 운영됩니다.

원격 및 CLI(명령어 인터페이스) 환경: 서버는 보통 모니터나 마우스가 없는 원격 상태(CLI)로 운영됩니다. 마우스 없이 키보드 명령어만으로 서버를 제어해야 하므로 리눅스 명령어 숙달이 필수적입니다.

보안 관제 및 로그 분석: 침해사고나 해킹 시도가 발생했을 때, 시스템 로그(log)를 실시간으로 분석하고 의심스러운 네트워크 연결 상태(netstat, ss)나 프로세스(ps)를 즉각 추적하여 대응하려면 리눅스 명령어가 가장 강력한 도구가 됩니다.

🐙 2. 개발자와 보안 담당자는 왜 '깃허브(GitHub)'에 코드를 올릴까요?
버전 관리 (Version Control): 코드를 수정하다가 에러가 나거나 문제가 생겼을 때, 과거에 정상 작동하던 시점으로 안전하게 되돌릴 수 있습니다(Git의 핵심 기능). 누가, 언제, 어떤 코드를 바꿨는지 기록이 투명하게 남습니다.

효율적인 협업: 여러 명의 팀원이 동일한 프로젝트나 보안 스크립트를 동시에 수정하더라도 코드가 꼬이지 않게 합치고(Merge) 관리할 수 있습니다.

포트폴리오 및 역량 증명: 개발한 프로그램(예: 미니 테니스 게임)이나 학습 포트폴리오를 웹상에 공개하여 자신의 기술 역량과 성장 과정을 가시적으로 보여줄 수 있습니다.

코드 공유 및 오픈소스 생태계: 유용한 보안 스크립트나 오픈소스 라이브러리를 공유하고 전 세계 개발자들과 협업할 수 있습니다.

💡 남에게 설명할 때 쓰는 핵심 한 줄 요약 (복습용)
리눅스 명령어란? "서버와 보안 시스템을 원격에서 빠르고 정확하게 제어하고 로그를 분석하기 위한 필수 운영 체제 제어 언어입니다."

깃허브란? "코드와 학습 기록의 수정 이력을 안전하게 관리하고, 다른 사람들과 협업하거나 나의 결과물을 증명하는 온라인 개발 포트폴리오 창고입니다."




1. 터미널 (Terminal)
무엇을 하는 프로그램인가요?

마우스로 아이콘을 클릭하며 조작하는 그래픽 환경(GUI) 대신, 키보드로 텍스트 명령어(글자)를 직접 입력해서 컴퓨터를 제어하는 프로그램입니다.

개발자나 보안 담당자는 마우스가 없는 원격 서버에 접속하거나 빠른 작업을 수행할 때 화면을 직접 보고 명령을 내리기 위해 터미널을 사용합니다.

2. 경로 (Path)
무엇을 나타내는 글자인가요?

컴퓨터 안에서 특정 파일이나 폴더가 정확히 어디에 위치해 있는지 알려주는 '주소'입니다.

현실 세계에서 집 주소(시·구·동·번지)가 있는 것처럼, 컴퓨터 속 파일도 현재 내가 어떤 폴더(디렉토리) 안에 들어가 있는지를 나타내는 경로 정보를 가지고 있습니다.

3. 깃배시 (Git Bash)
윈도우에서 왜 따로 필요한가요?

윈도우 운영체제에서 기본으로 제공하는 명령어 창(cmd, 파워셸)은 리눅스/유닉스 계열 서버나 개발 환경에서 쓰이는 표준 명령어와 문법이 다릅니다.

깃배시(Git Bash)는 윈도우 환경에서도 리눅스 명령어(Bash)를 그대로 쓸 수 있게 해주는 프로그램입니다. 윈도우 사용자가 리눅스 기반의 Git 명령어와 도구들을 오류 없이 원활하게 다룰 수 있도록 돕기 때문에 필수적으로 설치해서 사용하게 됩니다.
